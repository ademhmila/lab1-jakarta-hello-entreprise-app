# Lab 1: Hello Enterprise App

Companion to Chapter 1 &middot; Jakarta EE Fundamentals & IntelliJ Setup

## 📌 Project Overview
This repository contains the completed project for **Lab 1: Hello Enterprise App**, building the foundation of a Jakarta EE 11 enterprise application deployed on **WildFly 41 Application Server**.

## 🛠️ Tech Stack & Requirements
- **Java:** JDK 17+ (JDK 27 compatible)
- **Framework:** Jakarta EE 11
- **Application Server:** WildFly 41.0.1.Final
- **Build Tool:** Apache Maven (Wrapper included)
- **IDE:** IntelliJ IDEA Ultimate

## 🚀 Endpoints
Once the application is deployed on WildFly:
- `http://localhost:8080/jakartaee-course/` — Interactive JSP Dashboard
- `http://localhost:8080/jakartaee-course/hello` — `HelloServlet` (Step 6)
- `http://localhost:8080/jakartaee-course/goodbye` — `GoodbyeServlet` (Activity 1)
- `http://localhost:8080/jakartaee-course/api/hello-world` — Jakarta REST Resource
